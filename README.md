# 디지털 트윈·AI 개발 실험실

기능이 명확한 작은 프로그램을 만들고, 논문 근거·설계 판단·실행 검증을 함께 기록합니다.
첫 묶음은 2026-10-08 확인한 2026년 공개 논문 3편을 바탕으로 구성했습니다.
최신 동향의 전수 조사나 논문 모델의 재현 결과는 아닙니다.

## 바로 확인하기

Python 3.10 이상이면 외부 패키지 없이 실행할 수 있습니다. 저장소를 다운로드한 뒤 루트에서 실행하세요.

```bash
python -m unittest discover -s tests -v
python programs/2026-10-08/twin-command-guard/main.py
```

두 번째 명령을 실행한 뒤 http://127.0.0.1:8080 에서 제어 요청 검증 대시보드를 확인할 수 있습니다.
